Installing across ranges (say v1 on Angular 18) is blocked at three points:

  1. Install peerDependencies are a closed range, so npm 7+ refuses (ERESOLVE).
  2. ng add / ng update the schematic checks Angular first and tells you which wiratheme@ major to use.
  3. App start provideWiraTheme() and every component check VERSION.major and throw right away when it is out of range, in dev and production.

When you move Angular to another range (17 → 18, say), run ng update wiratheme: it moves the major and runs any migrations.

} @else {

ติดตั้งข้ามช่วงไม่ได้ (เช่น v1 ลง Angular 18) โดยกันไว้ 3 ชั้น

  1. ตอนติดตั้ง peerDependencies เป็นช่วงปิด npm 7 ขึ้นไปจะปฏิเสธ (ERESOLVE)
  2. ตอน ng add / ng update schematic ตรวจรุ่น Angular ก่อนแก้ไฟล์ และบอกว่าต้องใช้ wiratheme@ รุ่นไหน
  3. ตอนแอปเริ่มทำงาน provideWiraTheme() และทุก component ตรวจ VERSION.major ถ้าอยู่นอกช่วงจะ throw ทันที ทั้ง dev และ production

อัปเกรด Angular ข้ามช่วง (เช่น 17 → 18) ใช้ ng update wiratheme ซึ่งขยับ major ให้และรัน migration ถ้ามี API เปลี่ยน
