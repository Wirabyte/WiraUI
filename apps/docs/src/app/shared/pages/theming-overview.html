@if (en()) {

Three modes: 'none' (light values only), 'class' (toggled with .wu-dark on <html>) and 'media' (prefers-color-scheme). Or name your own class with darkModeSelector, e.g. '.my-dark'.

Dark-only themes (sayan-*, ratri-*, sila-dark-*, or definePreset(…, {{ '{' }} scheme: 'dark' {{ '}' }})) have no light values, so there is no class to toggle. The dark button on this site switches to the matching twin, such as sila-light-teal ↔ sila-dark-teal.

} @else {

ตั้งได้ 3 แบบ: 'none' (มีแค่ค่า light), 'class' (สลับด้วย .wu-dark บน <html>) และ 'media' (ตาม prefers-color-scheme) หรือตั้งชื่อ class เองด้วย darkModeSelector เช่น '.my-dark'

ธีมมืดอย่างเดียว (sayan-*, ratri-*, sila-dark-* หรือ definePreset(…, {{ '{' }} scheme: 'dark' {{ '}' }})) ไม่มีค่า light จึงไม่ต้องสลับ class ปุ่มโหมดมืดบนเว็บนี้สลับไปธีมคู่กันให้เอง เช่น sila-light-teal ↔ sila-dark-teal

} @if (en()) {

scale sets the root font size: 'sm' 12px, 'md' 14px, 'lg' 16px (the browser default), or a number of px. Every rem in the theme follows, so every component grows or shrinks together. Leave it out to keep the page's own root size. The "UI size" control in this site's theme panel does the same (this site starts at md).

} @else {

scale กำหนดขนาดตัวอักษรของ root: 'sm' 12px, 'md' 14px, 'lg' 16px (ค่าเริ่มต้นของเบราว์เซอร์) หรือตัวเลข px ทุกค่า rem ในธีมเปลี่ยนตาม ทุก component จึงเล็กหรือใหญ่ขึ้นพร้อมกัน ถ้าไม่ใส่จะใช้ขนาดเดิมของหน้าเว็บ ปุ่ม "ขนาด UI" ในแผงปรับธีมของเว็บนี้ทำแบบเดียวกัน (เว็บนี้เริ่มที่ md)
