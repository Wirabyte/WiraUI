@if (en()) {
Move an existing app without rewriting CSS

Familiar inputs and outputs (label, severity, (onClick) …), the p-* classes and theme variables your CSS already targets, and side-by-side use while you move page by page.

Thai by default

Thai locale and the Buddhist calendar built in, Thai fonts to choose from, and a line height that keeps Thai vowels and tone marks intact.

One set of CSS variables

Write themes in SCSS, CSS or TypeScript. @layer decides what wins, so !important and ::ng-deep can go.

NgModule and standalone in every version

Most of our apps are still NgModule-based, so every component ships both WuXxxModule and WuXxx, from v1 on.

} @else {
